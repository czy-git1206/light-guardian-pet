# Light Guardian Pet v1.0.0 / 光之守护者 v1.0.0

First public release.

## Highlights

- Windows transparent desktop companion with red and blue forms.
- Automatic form change every 3 minutes.
- Click interaction displaying “给你光的力量”.
- Automatic bottom-of-screen patrol after 5 minutes of inactivity.
- Six resize presets from 50% to 200%.
- Codex-compatible sprite version 2 package with 16 look directions.
- English and Simplified Chinese documentation.

## Download

Download `LightGuardianPet-v1.0.0.zip`, extract it, and run `launch.cmd`.
